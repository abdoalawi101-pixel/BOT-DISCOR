# 🤖 بوت تقديم إدارة ROMA

## 📦 طريقة التثبيت

### 1. تثبيت المكتبات
```bash
npm install
```

### 2. إعداد البوت
افتح ملف `bot.js` وعدّل قسم `CONFIG` في الأعلى:

```js
const CONFIG = {
    TOKEN: 'توكن_البوت_هنا',
    APPS_CHANNEL_ID: 'ID_قناة_استقبال_الطلبات',
    LOG_CHANNEL_ID: 'ID_قناة_السجلات',
    ADMIN_ROLE_ID: 'ID_رتبة_الإدارة',
    SERVER_NAME: 'ROMA',
};
```

### 3. صلاحيات البوت في Discord Developer Portal
اضمن تفعيل هذه الـ Privileged Intents:
- ✅ SERVER MEMBERS INTENT
- ✅ MESSAGE CONTENT INTENT

### 4. تشغيل البوت
```bash
node bot.js
```

---

## 🎯 طريقة الاستخدام

1. **إرسال البانل:** اكتب `!panel` في أي قناة (يشترط صلاحية Administrator)
2. **التقديم:** يختار العضو نوع التقديم من القائمة المنسدلة → يفتح نموذج → يملأه → يُرسل
3. **مراجعة الطلبات:** تصل الطلبات لقناة `APPS_CHANNEL_ID` مع أزرار قبول/رفض/مراجعة
4. **الإشعارات:** يتلقى المتقدم DM بنتيجة طلبه تلقائياً
